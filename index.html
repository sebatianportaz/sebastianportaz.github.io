scss sass

Sass es una herramienta para los creadores de páginas web que les ahorra tiempo, evita que repitan código y les permite organizar sus diseños de forma mucho más inteligente

Bootstrap

Bootstrap es una librería gratuita de herramientas y diseños web precalculados.En lugar de crear desde cero el estilo de cada botón, menú o formulario, Bootstrap te da componentes listos para usar que adaptan automáticamente tu página web a celulares, tablets y computadoras, permitiéndote maquetar mucho más rápido

Git - Git Hub

Git y GitHub son herramientas fundamentales para guardar, organizar y automatizar el desarrollo de software: Git funciona en tu computadora como una máquina del tiempo que registra cada cambio en el código para que puedas volver atrás si algo se rompe, mientras que GitHub es la plataforma en la nube donde resguardas ese código y colaboras con tu equipo; en desarrollo web permiten que varios programadores trabajen en distintas funciones de una misma página sin pisarse, y en DevOps sirven como el gatillo que activa procesos automáticos para probar y publicar cambios en el servidor al instante, solucionando de raíz problemas informáticos como la pérdida de archivos, el caos al trabajar en grupo o las caídas de sistema por errores no detectados

Javascript

JavaScript es el lenguaje de programación que le da interactividad y dinamismo a las páginas web; mientras que HTML define la estructura y CSS el diseño, JavaScript se encarga de que elementos como botones, menús desplegables, formularios, animaciones y mapas respondan en tiempo real a las acciones del usuario sin necesidad de recargar la página

Docker y Kubernetes

Docker empaqueta tu aplicación con todo lo necesario en un "contenedor" para que funcione igual en cualquier computadora o servidor (solucionando el problema de "en mi máquina sí anda"), mientras que Kubernetes administra y automatiza esos contenedores a gran escala, encargándose de repartir la carga de trabajo y reiniciar automáticamente cualquier contenedor que falle para garantizar que el sistema nunca se caiga

Submarine

Un Field Support Engineer (Ingeniero de Soporte en Campo) ayuda a una empresa brindando soluciones informáticas presenciales "en el terreno", resolviendo problemas complejos de hardware, redes, conectividad y software directamente donde ocurren; esto garantiza que las computadoras, servidores, impresoras y redes corporativas funcionen sin interrupciones, minimizando los tiempos de inactividad de los empleados y asegurando el correcto despliegue e instalación de nuevos equipos e infraestructura tecnológica en la compañía.
